# 双层非线性飞行控制实施

用户已授权实施。目标是在现有 Node/浏览器入口上增加轻量双层控制，不更改刚体/软体被控对象，不增加 npm 依赖。

1. 随项目携带 OSQP C 的预编译 WASM、许可证和可复建脚本。工具链仅用于维护者复建，普通用户不需要 Python/CMake/Emscripten。
2. 新增连续空中预测模型：实际喷口、气体消耗、阀门动态、六自由度姿态，阶段局部线性化。接触和结构变形仍由现有仿真处理。
3. 用稀疏 QP 支撑非线性轨迹优化；上层低频规划剩余飞行，下层短时域反馈跟踪。保留现有 CEM/MPC。
4. 接入原控制器加载、刚体运行和软体入口，记录实际支持范围、运行方法和计算耗时。

分工：GPT-6 Luna 子代理分别负责 WASM 封装、模型与 SQP、双层调度；主代理负责接口集成、审阅和运行核验。所有任务只在明确拥有的文件内写入。

验证限于实际需要的 QP 调用、模型数值检查、构建、代表性闭环及耗时比较，不新增测试框架或防御性回归体系。只读取原 Git 跟踪内容及本任务新建文件；保留 LOCAL_REPRODUCTION.md。

阶段边界：非凸问题采用局部优化，不承诺全局最优。首版面向连续空中着陆；复杂阶段约束、障碍、发动机离散启停及接触动力学尚须另行建模。实现和数值结果应分别报告，不把 API 接通当成着陆性能验证。
