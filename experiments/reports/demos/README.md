# 正式非凸 demo

正式展示仅保留两个案例；仓库跟踪配置、复现脚本和本目录指标，软体录制全部本地保存且 Git-ignored。

| 名称 | 配置 | 本地录制 |
| --- | --- | --- |
| 落地刹停.非凸 | `experiments/configs/nonconvex-stop.json` | `public/sims/flight-nonconvex-stop.sim` |
| 定点降落.非凸 | `experiments/configs/nonconvex-pad.json` | `public/sims/flight-nonconvex-pad.sim` |

运行 `npm run demos:generate` 生成两例，也可追加 `-- only=nonconvex-pad` 或 `-- only=nonconvex-stop`。
两例均使用 flat / seed 0、35% 主推进组最小指令、`2 / 关闭持续秒数` 重启惩罚、仅刹停地面控制。
刹停例采用更严格的 5° 接地/保持倾角与 0.5 rad/s 接地角速度判据，无固定落点，以 4 m/s 接地水平速度参考留给轮端制动；定点例检查 1.5 m / 0.5 m/s 触地约束。

定点例直接保留此前验收录制，配置已逐项核对，新增可选速度参考不改变其原参考值。
旧二开失败、对照与演进见 `experiments/archive/dual-development/`，不列入当前演示菜单。
在线仿真仍暂停实施。本文指标只覆盖两例固定初始条件，不作鲁棒性或实时性能承诺。

## 已核验结果

| 软体案例 | 接地水平速度 | 接地倾角 / 角速度 | 结果 |
| --- | ---: | --- | --- |
| 落地刹停.非凸 | 4.430 m/s | 1.96° / 0.121 rad/s | 保持最大 3.77°；1.018 s、1.24 m 内刹停，无车身/路缘碰撞 |
| 定点降落.非凸 | 0.054 m/s | 4.92° / 0.195 rad/s | 靶心误差 0.27 m，通过 1.5 m / 0.5 m/s 判据，无车身/路缘碰撞 |

刹停例采用 `level-land-stop`（≤ 5° / 0.5 rad/s）及更强姿态/角速度权重；定点例沿用原验收条件。
两例稳态最小推重比均约 1.085，指令下界审计零违规。实际点火过渡仍有阀门滞后。
刹停录制 6 s / 601 帧耗时 315.001 s，其中规划 56.6 s；定点原录制耗时 319.3 s，规划 67.04 s。
这里只报告具体运行耗时，不作实时性能承诺。

构建、复现入口子进程调用、任务继承、原定点/滑行参考保持及新参考端点检查通过。
刚体和软体闭环已运行；完整指标及先前失败尝试分别在同目录两份 JSON 中。
既有全套 parity/controller 失败未在本轮扩大处理，见归档 HISTORY.md。
